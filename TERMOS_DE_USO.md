# Termos de Uso da API de Papas

Última atualização: 8 de novembro de 2026

Estes Termos de Uso regulam o acesso e a utilização da **API de Papas**
(doravante "API"), desenvolvida por Enzo Bariotto como projeto acadêmico do
curso de Tecnologia em Sistemas para Internet do Senac. Ao acessar ou utilizar
a API, inclusive pela documentação Swagger, você declara que leu e concorda
com estes termos. Se não concordar, não utilize a API.

## 1. Sobre a API

A API é um serviço REST que disponibiliza informações sobre os papas da Igreja
Católica, seus conclaves, encíclicas, concílios e santos canonizados. Ela
permite consultar, cadastrar, atualizar e excluir registros, com finalidade
educacional e de demonstração.

## 2. Acesso

1. O acesso é gratuito e não exige cadastro ou autenticação.
2. A API é hospedada em um serviço de nuvem gratuito. Por isso, ela pode
   ficar fora do ar, demorar para responder na primeira requisição após um
   período sem uso, ou ser desativada a qualquer momento, sem aviso prévio.
3. O autor pode alterar, limitar ou encerrar a API, total ou parcialmente,
   a qualquer momento.

## 3. Dados armazenados

1. A API usa um banco de dados em memória. **Todos os dados cadastrados,
   alterados ou excluídos são perdidos** sempre que o serviço é reiniciado, e
   o banco volta ao seu conteúdo inicial de exemplo.
2. Os dados são **compartilhados entre todos os usuários**: qualquer registro
   que você cadastrar pode ser visto, alterado ou excluído por outras pessoas.
3. **Não envie dados pessoais, sensíveis ou confidenciais** por meio da API.
4. Os dados históricos de exemplo têm finalidade educacional, não constituem
   fonte oficial da Santa Sé e podem conter imprecisões.

## 4. Uso permitido

Você pode utilizar a API para estudar, testar requisições, desenvolver
aplicações de exemplo e fins acadêmicos em geral.

## 5. Uso proibido

Ao utilizar a API, você se compromete a **não**:

1. enviar conteúdo ilícito, ofensivo, discriminatório, difamatório ou que
   desrespeite a fé ou a dignidade de qualquer pessoa ou grupo;
2. realizar requisições em excesso, ataques ou testes de carga que
   sobrecarreguem ou prejudiquem a disponibilidade do serviço;
3. tentar explorar falhas de segurança, acessar áreas não destinadas ao
   público ou obter acesso não autorizado ao servidor;
4. utilizar a API com fins comerciais sem autorização prévia e por escrito
   do autor;
5. apresentar a API ou seus resultados como trabalho acadêmico de autoria
   própria.

O descumprimento destas regras pode resultar no bloqueio do acesso e na
remoção do conteúdo enviado, sem aviso prévio.

## 6. Privacidade

A API não solicita nem armazena dados de identificação dos usuários. O
provedor de hospedagem pode registrar informações técnicas das requisições,
como endereço IP, data e horário, de acordo com as políticas dele.
